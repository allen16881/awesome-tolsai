# TolsAI — multilingual AI tools directory

[TolsAI](https://www.tolsai.com/) is a curated directory of AI tools and apps in 10 languages, with daily picks, open-source recommendations, app listings and rankings.

- English: https://www.tolsai.com/
- 中文: https://www.tolsai.com/zh
- 日本語: https://www.tolsai.com/ja
- 한국어: https://www.tolsai.com/ko
- Open source: https://www.tolsai.com/open-source
- Submit a tool (account required, reviewed before publish): https://www.tolsai.com/submit
