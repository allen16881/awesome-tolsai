AI Inference on TolsAI

A snapshot of local and self-hosted ai inference engines and servers listed on TolsAI. This page shows 13 recent examples out of 13 live entries in the category (snapshot 2026-11-26). The live, complete list is on TolsAI.

  • rustling — A fast local inference engine for Inkling 2 Mini on Apple silicon, built for coding agents. · 中文
  • Openfal — Local image and video generation with a fal-compatible API and one-CLI setup. · 中文
  • vLLM Ascend — Community plugin that runs the vLLM inference engine on Huawei Ascend NPUs. · 中文
  • TrnRT — Open-source LLM inference engine for AWS Trainium with NKI megakernels, 1M-token context and an OpenAI-compatible API. · 中文
  • AI Infra in Depth (深入理解 AI Infra) — Free open-source book by Bojie Li on AI infrastructure: quantitative analysis of LLM inference and training system design. · 中文
  • ggml — Dependency-free C/C++ tensor library behind llama.cpp, with 2 to 8-bit quantization and CPU/GPU/NPU/browser backends. · 中文
  • Qdrant — Open-source Rust vector database and similarity search engine with payload filtering; managed cloud with a free tier. · 中文
  • AirLLM — Python library that runs 70B-class LLMs on a single 4GB GPU by loading layers one at a time, without quantization. · 中文
  • SGLang-Omni — Open-source multi-stage serving runtime from the SGLang project for omni, speech and TTS models, with OpenAI-compatible APIs. · 中文
  • colibri — Pure-C engine that runs huge mixture-of-experts models on an ordinary PC by keeping the active part in RAM and streaming experts from disk. · 中文
  • FreeToken — Open-source edge-native MoE serving engine for running frontier-scale open-weight models (290B+ MoE) locally on consumer NVIDIA GPUs. · 中文
  • spinf-serve — Open-source inference server for bulk classification: reads content once and returns calibrated probabilities for many questions on one GPU. · 中文
  • Magnitude — Open-source local inference engine that auto-tunes kernels for your hardware, claiming over 2x Ollama speed, with one-click agent connections. · 中文
